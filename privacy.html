Privacy Policy

TickSim Uploader · last updated 28 October 2026

Whose data

The tool connects only to the TickSim channel's own TikTok account and its own YouTube channel. It has no other users and collects no data from viewers or other users.

What it stores

  • The access and refresh tokens TikTok issues when the account owner approves the tool, plus the account's open ID and display name (to confirm the right account is connected).
  • The publish IDs and status TikTok returns for each video it posts.

These are stored only on the creator's own computer, are never sold or shared, and are used only to post TickSim's videos.

YouTube

On YouTube the tool uses the YouTube Data API to upload TickSim's own videos to its own channel, set their titles, thumbnails, captions and playlists, read their view counts, and post the channel's own comment under each video. Google access tokens are stored only in the creator's own automation software (n8n) on their own computer. TickSim Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

TikTok scopes used

  • user.info.basic: to show which account is connected.
  • video.publish: to post TickSim's videos directly to its profile.
  • video.upload: to send a video to the account's TikTok inbox as a draft when direct posting isn't available.

Deleting data

Revoking the app in TikTok (Settings → Security and permissions → Manage app permissions) stops all access; the stored tokens are then deleted.
